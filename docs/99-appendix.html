Vocabulary for reading a GWAS table

Term Meaning here
Variant row An association summary for a genomic variant, not a participant
Genome build Coordinate reference; positions from different builds are not interchangeable
Effect allele The allele to which beta and its frequency refer; not automatically minor, reference or harmful
Beta Change on the stated quantitative-trait scale per copy of the effect allele
SE Standard error on the beta scale
Source p-value The released association-test result, retained separately from derived checks
EAF / MAF Effect-allele frequency / smaller of EAF and 1−EAF
INFO A source-defined imputation-quality metric when supplied
LD Correlation among variants; position alone does not measure it
Locus / causal gene A regional or biological interpretation requiring more than a list of small-p rows

Reference arithmetic

For a quantitative beta estimate and positive SE:

\[ z=\frac{\beta}{SE},\qquad CI_{95\%}=\beta\pm 1.959964\,SE. \]

The derived two-sided normal Wald p-value is \(2\Phi(-|z|)\). It does not establish which test produced a source p-value. Preserve source methods and source values.

The plotted strength is \(-\log_{10}(p)\). Smaller p produces a higher point, not necessarily a larger effect. Precision and sample support influence significance.

Verification row z Source −log10(p) Derived Wald −log10(p)
SYN000001 6 8.704834 8.704834
rs3764261 61.846154 768.856985 832.466119

The synthetic source uses the same normal formula. The GLGC source uses corrected meta-analysis results (Willer et al. 2013; Global Lipids Genetics Consortium n.d.). Both rows illustrate correct arithmetic; they do not imply the same test definition.

Very small positive p-values

Binary64 cannot represent every probability in a released GWAS file. The guide retains source p-value strings, using decimal logarithms for extreme values. Thus 1.39e-769 remains a positive source result; it is not replaced by zero or floored at an arbitrary minimum. Read p_value as text when independently inspecting such rows.

The verifier uses a stable normal-tail approximation for large z. An ordinary floating-point Wald probability may underflow, while its log remains finite. Compare named log quantities and state their test definitions.

Frequencies, support and missing quality fields

MAF is \(\min(EAF,1-EAF)\). Changing the named allele reverses beta and replaces EAF by 1−EAF when the allele pair is properly aligned. It does not change MAF or a two-sided normal test.

Reference-panel frequency is not the frequency measured in every study cohort. The GLGC release supplies 1000 Genomes EUR frequency; the guide labels its basis and records exclusions for unavailable values. Other sources require their own documentation.

N is a per-variant source field, not the number of association rows. Some GLGC N values contain decimals; the guide preserves reported values without claiming why they are non-integer. It does not assume actual N and effective N are interchangeable.

If INFO is absent, metadata explicitly declares that absence and the filter is not applied. A missing distribution is not evidence of good imputation. Never fill an absent quality field with 1 merely to pass validation.

Filtering and display

The importer audit describes source-to-prepared transformations. The workflow audit describes MAF/INFO filtering of prepared rows. Their denominators differ; report both.

Summary calculations use every retained row. Dense scatters retain all p≤1e-5 rows and reproducibly sample at most 50,000 other background rows by default. The exact displayed rows and policy are recorded. Do not estimate variant counts from visible dots.

For Q–Q, ranks are selected from the full sorted distribution. With \(m\) retained rows and rank \(i\), the reference probability is \((i-0.5)/m\). The shaded interval uses beta order-statistic quantiles under independent uniform null p-values. It is pointwise, not a simultaneous or LD-adjusted band. Dense points need not imply independent tests.

Lambda and multiple testing

Lambda GC is the median chi-square(1) value transformed from source p-values divided by the chi-square(1) null median (Devlin and Roeder 1999). It is a diagnostic, not a correction applied by this guide or a proof of study validity. Source correction, true signal, sample size, variant selection, correlation and model issues influence interpretation.

The default p≤5×10⁻⁸ line is a declared reference for this worked example. A new study needs a justified multiple-testing plan. Threshold-crossing variants are not automatically independent loci, and a new threshold is not justified merely by counting a teaching subset.

A top-variant forest plot has selection bias and nearby rows may be correlated. Its nominal intervals are not simultaneous intervals or intervals adjusted for selection. The GLGC source test is not reconstructed by those intervals.

What requires additional evidence

Current result Additional work before a stronger claim
A regional association cluster Appropriate LD and study definitions before counting independent signals
A position near a gene Build-matched annotation and biological evidence before causal-gene assignment
A small p-value Effect units, source method, replication and study limits
A trait association Separate causal design before an intervention or clinical conclusion
A useful synthetic demonstration Verified real data before a biological finding

Summary-statistics QC benefits from source-level organization, explicit diagnostics and documented decisions (Winkler et al. 2014). The simplified TSV/JSON contract here is not a full GWAS-SSF validator (GWAS Catalog n.d.).

Reproducibility and scope

Keep prepared inputs, original source records, importer, parameters, analysis code, environment and report. SHA-256 hashes identify files; they do not validate scientific meaning. Version ranges and a run record do not constitute an exact portable environment lock.

The synthetic design is documented in data/provenance/SIMULATION-DESIGN.md. It uses invented coordinates, a frequency mixture, variable coverage and simulated local correlation. Its SE approximation is \([2N\,MAF(1-MAF)\,INFO]^{-1/2}\) except the fixed reference row. It supplies no empirical LD or genotype-model truth.

The real-data case inspects one published HDL release. It does not reproduce all lipid traits, original cohort QC, meta-analysis, LD analysis, enrichment or functional experiments from the paper.
