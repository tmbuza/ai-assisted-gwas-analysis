# AI-Assisted GWAS Analysis with Python

A CDI guide for moving from quantitative-trait GWAS summary statistics to figures, checked numerical evidence and a defensible report.

## Start here

Read `00-setup.qmd` or open the rendered guide at `docs/index.html`. The book follows the same seven-step structure as the other CDI guides, with shared setup/workflow/reporting chapters.

| Example | Included evidence |
|---|---|
| Synthetic | 22,000 fictional rows; 15,760 retained; independent SYN000001 verification |
| GLGC HDL | 2,261,360 prepared source rows; 2,058,079 retained; rs3764261 verification |
| Your study | Input contract, decisions, commands and a reusable report template |

GLGC original release: Willer et al. (2013), doi:10.1038/ng.2797; https://csg.sph.umich.edu/willer/public/lipids2013/. The prepared gzip input, metadata, audit and compact figure evidence are included. The two large full-row GLGC audit/results tables are regenerated by the analysis command, rather than bundled.

## Run from the project root

With your Python environment active:

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m pip check
python scripts/python/run_workflow.py --data-dir data/synthetic --output-dir results/synthetic
python scripts/python/verify_variant.py data/synthetic results/synthetic SYN000001
python scripts/python/run_workflow.py --data-dir data/glgc-hdl --output-dir results/glgc-hdl
python scripts/python/verify_variant.py data/glgc-hdl results/glgc-hdl rs3764261
quarto render
```

Quarto is separate from Python. Rendering displays saved figures; it does not run analyses. The full GLGC run requires several GB of available memory, several minutes and several hundred MB of output space. Learners can read the included real-data figures and compact evidence before running it.

Maintainer source reproduction:

```bash
python scripts/python/prepare_glgc.py
```

This downloads the checksum-pinned source (approximately 59 MB) into ignored `source/`, audits source-to-prepared exclusions and reproduces the prepared file. Source p-value strings and reported N decimals are preserved. No INFO values are invented. See the real-study lessons for reference-frequency and meta-analysis context.

## Outputs and limits

Ten figure families use Matplotlib/Seaborn and PNG only. A long-tail Manhattan view retains the full range and adds a clearly labelled detail panel. Dense scatter backgrounds are sampled for drawing only; counts, top selection and diagnostics use the full retained file. Full-row outputs above 100,000 input variants are compressed `.tsv.gz`.

The guide starts from autosomal biallelic SNV quantitative beta summaries. It does not fit genotype models, perform LD clumping/fine mapping, identify causal genes or predict clinical risk. Source and derived normal Wald p-values are distinct. INFO availability and frequency basis are explicit metadata.

## Project map

| Folder | Contents |
|---|---|
| `examples/` | Synthetic, GLGC real-study and own-study seven-step lessons |
| `data/` | Prepared inputs, metadata and provenance |
| `config/` | Reference parameters |

Learner `reports/`, environments, caches and downloaded original sources are ignored. Retain citations and source data-use terms; this project does not relicense original study data. See `VALIDATION.md` for the checks performed.
